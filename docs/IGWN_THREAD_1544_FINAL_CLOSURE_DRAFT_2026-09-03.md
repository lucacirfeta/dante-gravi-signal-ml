# IGWN thread #1544 — final closure draft

Status: **final copy; authorized for posting; not yet posted**
Date: 3 September 2026

Thank you again to everyone who reproduced and discussed this case, in
particular Kretski. We have now completed the provenance-locked O4a
reconstruction with symmetric whitening context, a detector-aware native
reference index, detector-specific recalibration, physical-coincidence
follow-up, and PEM screening.

The audit identified a boundary-condition defect in a later frozen catalogue
generated by the published whitening and scoring path. The intended input for
each 32-s analysis window was 40 s of strain: 4 s of context on both sides,
followed by whitening and cropping. For 169 of 10,429 frozen detector--GPS
windows, the historical path crossed an HDF5 boundary and supplied only 36 s,
omitting the right context. In a controlled replay using the historical
representation and detector-specific thresholds, restoring the complete
context changed 120 class assignments and reversed 97 routing decisions, all
from `ESCALATE` to `ROUTINE`.

The subsequent end-to-end reconstruction rebuilt both the detector-aware
representation and calibration. It produced 10,942 corrected candidates. The
comparison contains 10,022 shared identities, 407 historical-only identities,
and 920 corrected-only identities; 1,626 shared class assignments differ.
These broader differences must not be attributed solely to the padding defect
because the representation and thresholds changed together.

For the L1 analysis window starting at GPS 1382955232, with the feature
localized near GPS 1382955253.17, the corrected native classification remains
`ROBUST` (score 0.6122661233). The opposite-detector partner was evaluated
regardless of its class or presence in the candidate catalogue. The event does
not exceed the corrected pooled null threshold used to select cross-detector
coincidence follow-ups and is not among the 65-event PEM shortlist (9 `ROBUST`
primary targets plus 56 `AMBIGUOUS` diagnostic targets). Consequently there is
no new corrected cross-detector support for this event and no PEM result to
report for it.

The bounded interpretation is therefore that it remains a strong
single-detector anomaly. Its instrumental origin is consistent with the
available public-data evidence, but remains an inference rather than a proven
identification. The pooled-null threshold is a diagnostic follow-up rule, not
a formal globally trial-corrected significance claim.

We are preserving all historical artifacts. A v2 correction for
arXiv:2606.25702 has been submitted and is awaiting public posting; I will add
the public link when it becomes available. The corrected evidence and
provenance are currently available on the repository branch
`codex/dante-light-o4a-v1-parity`, in particular
`corrected_native_coincidence.json` and
`corrected_final_impact_attribution_v1.json` under
`artifacts/dante_light/o4a_v1_parity/`.

This message is intended to close the specific status question raised in
thread #1544, not to make a discovery claim.

# O3a native detector-specific thresholds

Implement a thin adapter around the existing block-bootstrap helper. Bind the
verified native rescore, native calibration identity contract, approved O3a
stage statistics, canonical runtime and implementation bytes before execution.
Preserve the O4a native method: p99 over all 5,000 detector-local calibration
rows; 1,000,000 replicates, seed 42, blocks of 17 over the first 4,998 rows,
CI percentiles 2.5/97.5. All values must come from versioned contracts.

1. Validate metadata, identity/order/block geometry, score encodings and parent
   hashes. Test synthetic fixtures, corruption, exact block resampling, tail
   exclusion, deterministic verification and singleton locking before freeze.
2. Freeze source/contract and commit before fitting. Run only in canonical WSL.
   Do not use candidate scores for fitting; parent integrity verification is
   permitted. Do not change historical contracts or normalize their source files.
3. Recompute the thresholds independently through --verify. Report absolute
   and relative CI widths without a new post-hoc acceptance cutoff. Require
   regression tests and provenance checks, then publish the branch checkpoint.

No classification, taxonomy, coincidence or PEM is opened by this plan. A new
scientific decision or failed provenance check requires a stop and review.

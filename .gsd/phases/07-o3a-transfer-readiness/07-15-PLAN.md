# Plan 07.15: O3a native score-only replay

<objective>
Score the frozen 10,000 native-calibration windows and every frozen O3a
primary-candidate identity against the already verified O3a-only native index.
This stage computes no native threshold, class, taxonomy or significance.
</objective>

<method_boundary>
- Bind the exact PASS primary scan, native index, native-calibration cohort and
  canonical WSL runtime by their verified digests. Preserve all earlier runs.
- Use the O4a corrected native-rescore method: exact symmetric 4 s context,
  whitening before 32 s crop, Q-transform/cividis representation, DINOv2
  patch tokens, and PatchScorer score-only with top-k from the versioned
  O3a/O4a method contracts. Do not import O4a scores, thresholds or rows.
- Replay the complete SHA-256 of each consumed raw frame and the primary-scan
  image SHA-256 of every scored window. Bind calibration context-source
  identities to the frozen cohort ledger; reject missing, changed, duplicate
  or nonfinite rows. No silent fallback to another frame or cached score.
- Preflight every detector/GPS identity and source-frame dependency before
  opening strain. The measured workload is 18,900 windows, 4,324 distinct
  source frames and 525,228,850,105 source bytes. These are resource counts,
  not outcome-bearing results; recalculate and verify them from parents.
- Process exact source frames with verified transient reuse and bounded disk
  occupancy. Resume only complete, hash-verified score shards under the same
  run key. On a scientific or structural failure, retain the failed run and
  stop. Do not overwrite divergent evidence.
</method_boundary>

<tasks>
1. Implement the versioned score-only contract and identity/source-frame
   preflight. Unit-test dependency completeness, cross-frame stitching,
   parent and SHA mutation rejection, duplicate identity rejection, and
   absence of outcome fields in progress evidence.
2. Implement and test raw-frame reuse, replay, scoring, atomic shards and
   fail-closed verifier in canonical WSL/CUDA. Confirm a real HDF5/CUDA
   preflight before the full run. Freeze code/config before any full scoring.
3. Run and independently verify exactly 5,000 calibration scores per detector
   and all frozen primary-candidate scores. Require zero source, context,
   image, encoder, score or provenance mismatches. Commit/push only this
   branch after test PASS.
</tasks>

<next_gate>
Only after this rescore verifies may detector-specific native p99 thresholds
and block-bootstrap confidence intervals be computed. Candidate classes,
coincidence, PEM and any physical interpretation remain downstream. A pooled
diagnostic null is not global discovery significance.
</next_gate>

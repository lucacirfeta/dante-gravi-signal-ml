# O3a atomic raw downloader

## Goal

Implement and verify a resumable, content-addressed downloader for the 726
frozen O3a source frames, with a disk/network preflight and an atomic final
raw manifest.

## Tasks

1. Bind a download run key to the frozen acquisition plan and downloader
   implementation.
2. Resolve content lengths with HEAD requests and fail closed when free space
   plus a declared reserve is insufficient.
3. Stream HTTPS bytes to `.part`, resume only valid range responses, validate
   HDF5 metadata, hash complete files, and rename atomically.
4. Persist progress and verified-file records so interruption never requires
   restarting verified files.
5. Publish the PatchProducer-compatible raw manifest only after every planned
   frame is verified.
6. Test failure, resume, path-safety, HDF5, manifest, and preflight behavior
   before starting the real transfer.

## Completion gate

Downloader tests pass on Windows and WSL, the implementation is committed and
pushed before execution, and a real preflight proves the transfer fits on
`E:`. Scientific raw acceptance and scoring remain disabled.

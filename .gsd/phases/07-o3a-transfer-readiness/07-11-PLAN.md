# Plan: O3a primary scan

## Objective

Freeze and launch the complete O3a primary scan over the already frozen
CBC_CAT1, 32-second, complete-context identity universe using the verified
detector-specific p99 thresholds from plan 07-10.

## Scientific boundary

- Score exactly 349,925 H1 and 372,986 L1 identities once each.
- Use the frozen O3b K=275 seed representation and the H1/L1 p99 point
  thresholds without pooling or retuning.
- Candidate materialization is strictly `primary_score > detector_p99`.
- Store full MIL candidate tensors only for threshold exceedances.
- Do not classify natively, choose the native cohort, build an index, run
  coincidence/PEM, or inspect intermediate candidate outcomes.
- Download non-calibration raw frames only into a bounded transient cache;
  retain frame hashes in the database and remove processed temporary frames.

## CI-asymmetry annotation

The wider L1 p99 interval may reflect detector-specific score-tail
heterogeneity, nonstationarity, or calibration-population composition.  This
is an explicit non-causal hypothesis, not an established detector diagnosis.
Gross CBC_CAT1 duration and segment count alone do not establish the cause;
the asymmetry must be checked again at native calibration and final thresholds.

## Tasks

1. Implement and test a provenance-bound, resumable, frame-streaming scanner.
2. Freeze its contract against the verified thresholds, source inventory,
   identity universe, raw manifest, runtime, and implementation hashes.
3. Run Windows and WSL regression tests plus a real HDF5/CUDA preflight.
4. Commit and push the frozen implementation on the science branch.
5. Launch exactly one background scan and monitor process, progress, SQLite,
   transient-cache bounds, and failure evidence without revealing outcomes.
6. On completion, verify exact cardinality, database hashes, tests, and
   provenance before any downstream stage opens.

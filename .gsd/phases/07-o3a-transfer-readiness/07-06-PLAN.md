# O3a initial-calibration selector freeze

## Goal

Translate the author-approved hash-stratified complete-block rule into an
exact, outcome-blind, deterministic selector and freeze the first 5,000
planned identities per detector without reading strain.

## Tasks

1. Form non-overlapping 17-window blocks within each CBC_CAT1 segment from
   the frozen 64 s proposal universe.
2. Partition the chronological block list into 295 integer-quantile strata.
3. Rank blocks within each stratum by the frozen SHA-256 key and choose rank
   zero for the preselection plan.
4. Freeze 5,000 rows per detector: 294 complete bootstrap blocks (4,998 rows)
   plus two point-estimate-only tail rows.
5. Freeze raw acceptance and same-stratum fallback semantics without running
   them or inspecting strain, scores, or outcomes.
6. Verify deterministic regeneration and fail closed on any contract or plan
   drift.

## Completion gate

The contract and preselection plan regenerate byte-identically, contain 295
selected blocks and 5,000 planned rows per detector, bind all parent evidence
and implementation sources, and authorize no strain access.

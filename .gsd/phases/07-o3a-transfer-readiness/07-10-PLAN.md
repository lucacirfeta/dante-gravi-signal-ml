# Plan: O3a initial detector-specific p99 thresholds

## Objective

Freeze, fit, and independently replay the initial O3a p99 thresholds from the
already accepted 5,000-row H1 and L1 primary-score populations.  Report the
realized 95% block-bootstrap interval widths before authorizing any primary
scan.

## Scientific boundary

- Use only the accepted initial-calibration ledger bound by plan 07-09.
- Fit H1 and L1 separately; pooling is forbidden.
- Point p99 uses all 5,000 detector rows.
- The bootstrap uses the first 4,998 rows as 294 complete, non-overlapping
  17-row temporal blocks, with the already approved seed, replicate count,
  chunk size, and confidence percentiles.
- Do not classify, inspect candidates, select the native cohort, or start the
  primary scan.
- The pre-existing fail-closed adequacy gate is finite, nondegenerate H1/L1
  intervals containing their point estimates.  Report absolute width and
  width as a fraction of p99; do not invent an O3a-specific cutoff post hoc.

## Tasks

1. Add and test a provenance-bound threshold contract and deterministic runner.
2. Freeze the contract against the verified acceptance summary and ledger.
3. Execute and independently replay one million block-bootstrap replicates per
   detector.
4. Record p99, interval endpoints, and interval widths in the phase evidence.
5. Stop before the primary scan and present the realized widths to the author.

# O3a initial-calibration raw acceptance

## Goal

Freeze, implement, and verify the first strain-reading O3a gate: block-atomic
raw acceptance and primary O3b-K275 scoring for the 590 provisionally selected
initial-calibration blocks.  Do not fit thresholds, classify candidates, or
select the native-index population.

## Tasks

1. Bind the run identity to the approved stage/selector/calibration contracts,
   the verified raw manifest, the canonical WSL/CUDA runtime, the frozen
   O3b-K275 reference, and the versioned parity Top-k value.
2. Read exact 4 s + 32 s + 4 s contexts directly from the verified HDF5 files
   and reject non-finite or incomplete raw data.
3. Apply canonical whitening-before-crop, Q-transform, frozen DINOv2 encoding,
   and O3b-K275 scoring with explicit finite checks at every required stage.
4. Accept or reject all 17 rows of each proposal block atomically.  Never use
   score magnitude or class for acceptance and never reallocate across strata.
5. Persist content-addressed block shards and progress atomically so an
   interrupted run resumes without rescoring verified blocks.
6. Publish the 5,000-row-per-detector calibration ledger only if all 590
   provisional blocks pass.  Otherwise fail closed and require a versioned
   same-stratum fallback acquisition extension.

## Completion gate

The contract and implementation are committed and pushed before real strain
execution; focused tests pass on Windows and WSL; the real WSL/CUDA run either
produces exactly 10,000 accepted point-estimate rows with 9,996 bootstrap rows,
or stops with explicit block failures and no calibration threshold.

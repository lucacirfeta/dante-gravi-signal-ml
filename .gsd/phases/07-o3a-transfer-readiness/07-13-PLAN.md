# O3a detector-aware native index

## Goal

Build a fresh O3a-only native VQ reference from the verified 647 H1 + 647 L1
clean-window cohort. Reuse the approved O4a architecture, not O4a scientific
rows, tokens, centroids, or scores.

## Frozen method and execution gates

1. Bind a content-derived run key to the approved O3a stage contract, frozen
   cohort, canonical WSL/CUDA runtime, method reference, and exact source bytes.
2. Replay each cohort row's retained raw-context file hash and value hash,
   context geometry, whitening-before-crop, clean-window hash, excess-power
   disposition, Q-transform image, and DINOv2 patch tokens.
3. Write one atomic, identity-bound token shard per cohort row. A retry may use
   a shard only after its file, byte, identity, and replay hashes are verified.
4. Assemble tokens in frozen cohort-ledger order. Fit the versioned historical
   MiniBatchKMeans architecture: K=1216, seed 42, batch 4096, `n_init=auto`,
   50,000 sampled raw embeddings, and L2-normalized centroids and sample.
5. Verify exactly 1,294 replay rows, 1,771,486 patch tokens, output hashes,
   numerical shapes and norms. Preserve all failures and superseded runs.

## Boundary

The source-frame hashes were checked at the cohort stage. The full raw frame
archive is not retained for this index stage; the exact 40 s raw contexts are.
No native calibration, rescoring, threshold, candidate class, or cross-detector
claim is opened by this index build.

## Scientific review gate and resolution

On 4,096 Hz O3a data, GWPy 4.0.1's `QTiling` reduces the requested
`frange=(20, 2048)` under `qrange=(4, 64)` to the effective
`(20, 1291.0530521679268)` Hz. The initial interpretation incorrectly
identified O4a as a 16,384 Hz production method. The corrected-O4a native
index contract and execution instead use 4,096 Hz, and an O4a preflight
records the same GWPy cap. This is a requested-versus-effective-band metadata
distinction shared by both runs, not an O3a-only comparability failure.

On 2026-09-23 the author chose 4 kHz method parity. The index was re-verified
without recomputation and accepted for the next O3a stage. A paired 16 kHz
O3a/O4a band-extension study is future, separate work, not part of this plan.

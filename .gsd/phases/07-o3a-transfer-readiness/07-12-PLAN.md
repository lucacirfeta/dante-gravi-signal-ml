# O3a detector-aware native cohort

## Goal

Freeze the fresh O3a-only detector-aware cohort used to build the native
index.  Selection must use only detector/GPS identity plus the already-frozen
primary-candidate firewall; no primary score, class, native representation,
or downstream outcome may influence membership.

## Frozen scientific rules

- Select exactly 647 rows for H1 and 647 rows for L1.
- Rank identities by SHA-256 of the approved stage-contract digest, detector,
  and integer analysis GPS start.
- Exclude every primary candidate and every identity within the inclusive
  cross-detector 128 s start-time guard.
- Require at least 96 s separation between retained identities in the same
  detector.
- Require exact 4 s symmetric context, canonical whitening, a finite 32 s
  clean crop, and the corrected-O4a parity excess-power veto.
- Retain exact raw 40 s contexts and source-frame hashes only for accepted
  rows on drive E.
- Select the native-calibration validation population only after this cohort
  and its index manifest exist; that later population must be disjoint and
  guarded against both candidates and index windows.

## Tasks

1. Freeze a hash-bound cohort contract and deterministic proposal selector.
2. Bind the contract to the verified O3a primary-scan database, the canonical
   WSL runtime, the frozen source inventory, and the O4a parity method.
3. Add a no-strain preflight that verifies proposal capacity, exact source
   provenance, and bounded storage capacity.
4. Add resumable fail-closed raw-quality execution and independent structural
   verification.
5. Pass focused Windows and WSL regression suites before execution.

## Completion gate

The final ledger contains exactly 647 unique clean rows per detector, every
row passes the candidate firewall and separation rules, every retained raw
context and source hash verifies, and no native embedding or score has been
computed during cohort selection.

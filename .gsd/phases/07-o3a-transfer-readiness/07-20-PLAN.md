# O3a/O4a public common-channel PEM comparison

## Author decision and interpretation boundary

On 2026-09-26 the author chose a **new, paired O3a/O4a PEM follow-up using
the same publicly verifiable channels at each detector**, rather than calling
different O3a/O4a channel sets methodologically equivalent. The corrected
O4a PEM v1 outputs and O3a coincidence outputs remain immutable. This is a
new comparative measurement, not a replacement of the historical O4a PEM
receipt and not a claim of global significance or astrophysical origin.

The six O4a-contract channel names absent from the public O3a NDS2 inventory
must **not** be described as six sensors that physically did not exist. At
least `H1:IMC-WFS_A_DC_PIT_OUT_DQ` and
`H1:IMC-WFS_A_DC_YAW_OUT_DQ` were documented before O3. The public O3
release is a selected auxiliary-channel subset. There is no documented and
publicly available one-to-one O3a alias for any of the six absent names in
the inspected inventory. In particular, the O3a-public
`H1:LSC-REFL_A_LF_OUT_DQ` and `H1:LSC-REFL_A_RF9_Q_ERR_DQ` are not silently
interchangeable with O4a's `H1:LSC-REFL_A_RIN_OUT_DQ`.

Sources: [GWOSC O3 auxiliary release](https://gwosc.org/O3/auxiliary/),
[GWOSC O4 auxiliary release](https://gwosc.org/O4/auxiliary/), and
[pre-O3 LIGO H1 IMC-WFS channel documentation](https://dcc.ligo.org/public/0152/G1800941/001/LIGOstatus.pdf).

## Read-only preflight evidence, 2026-09-26

- Exact-name NDS2 inventory, `nds.gwosc.org` epoch `O3a`, intersected with
  `config/dante_o4a_corrected_native_pem_v1.json`: 5/9 H1 and 5/7 L1
  non-excluded channels. No O3a alias was inferred from name similarity.
- H1 common set: `H1:CAL-PCALY_RX_PD_OUT_DQ`,
  `H1:LSC-POP_A_LF_OUT_DQ`, and
  `H1:SUS-ETMX_L{1,2,3}_CAL_LINE_OUT_DQ` (three separate channels).
- L1 common set: `L1:ASC-X_TR_A_NSUM_OUT_DQ`,
  `L1:CAL-PCALY_RX_PD_OUT_DQ`, and
  `L1:SUS-ETMX_L{1,2,3}_CAL_LINE_OUT_DQ` (three separate channels).
- The O3a verified coincidence receipt selects 12 targets: 3 H1 and 9 L1.
  All five common channels cover the full 32-second event window for every
  corresponding target (H1 3/3 per channel; L1 9/9 per channel).
- Using the frozen 8,900-row O3a classification ledger for candidate
  exclusion, the existing corrected-O4a background-span picker found a
  4-hour CAT1 span with at least 60 clean windows for each of the 12 O3a
  targets. The selected clean-window counts were 61--129. NDS2 metadata
  confirmed continuous full-span availability for all five common channels
  at each target (H1 3/3; L1 9/9). This is metadata coverage, not a data
  fetch, coherence result, or success claim for the new PEM computation.
- GWOSC `CBC_CAT1` and `BURST_CAT1` segment lists were compared over the
  entire O3a GPS interval for each detector and were exactly equal: H1
  545/545 segments, L1 535/535. The O3a frozen CBC_CAT1 population and
  O4a PEM background picker using BURST_CAT1 therefore select the same
  O3a public CAT1 intervals; this equality must be rechecked in the new
  verifier, not assumed from label similarity.
- All five common channels were event-available and included in the
  archived O4a PEM v1 calibrations for all 34 H1 and 31 L1 historical
  targets. This is **not** a substitute for recomputing the family-wise
  O4a null with only the common five channels. O4a's historical 9/7-channel
  family-wise thresholds and verdicts cannot be reused as if they were
  five-channel thresholds.

The two explicitly excluded L1 PEM channels remain excluded in both runs.
The common five-channel public subset does not establish that unreleased
environmental or instrumental sensors are quiet.
